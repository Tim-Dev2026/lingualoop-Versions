# LinguaLoop 1.0.0 — erste Veröffentlichung

Assets für dieses Release:
- `LinguaLoop-Setup-v1.0.0.exe`: einzelnes Setup für neue Nutzer; installiert LinguaLoop und richtet den Update-Prüfer im Autostart ein.
- `LinguaLoop-v1.0.0-win-x64.zip`: Update-Paket für den automatischen Updater.

Die App prüft beim Start sowie beim Windows-Login auf neuere GitHub-Releases und installiert neue Versionen automatisch. Der Lernstand bleibt lokal gespeichert.
