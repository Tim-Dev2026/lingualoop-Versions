# LinguaLoop 1.2.0

- Modernisiertes Windows-App-Design mit Petrol-/Navy-Farbpalette, abgerundeten Karten und Schaltflächen.
- Der Tab **Presets** zeigt vorerst „Kommt bald“.
- Neuer Tab **Design** mit „Kommt bald“.
- Das Setup enthält den Deinstaller und erstellt eine eigene Desktop-Verknüpfung dafür.
- Persönliche Vokabeln und Lernfortschritte bleiben lokal.

## Release-Dateien

- `LinguaLoop-Setup-v1.2.0.exe` — Installer für Windows x64.
- `LinguaLoop-v1.2.0-win-x64.zip` — Paket für automatische Updates.
