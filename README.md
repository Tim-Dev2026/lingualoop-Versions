# LinguaLoop

**Französisch-Vokabeln lernen – mit eigenen Wortlisten und lokalem Lernstand.**

## Windows-Download

[![LinguaLoop herunterladen](https://img.shields.io/badge/Windows-LinguaLoop_herunterladen-168777?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/Tim-Dev2026/lingualoop-Versions/releases/download/v1.2.0/LinguaLoop-Download-v1.2.0.zip)

Der Download ist eine ZIP-Datei. Entpacke sie und starte darin **LinguaLoop-Setup-v1.2.0.exe**. Das Setup installiert die App, französische Offline-Stimme, Updater und Deinstaller. Anschließend klickst du im Setup auf **Installieren**.

Der Button funktioniert, sobald `LinguaLoop-Download-v1.2.0.zip` am Release v1.2.0 angehängt und der Entwurf veröffentlicht ist.

## Version 1.2.0

- Modernisiertes Design mit Petrol- und Navy-Farben, runden Karten und Schaltflächen.
- Der Tab **Presets** zeigt vorerst „Kommt bald“.
- Neuer Tab **Design** mit „Kommt bald“.
- Vokabeln und Lernfortschritt bleiben lokal auf dem PC.
