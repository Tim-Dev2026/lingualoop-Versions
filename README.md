# LinguaLoop – Updates

Dieses öffentliche GitHub-Repository stellt LinguaLoop-Downloads und Versionshinweise bereit. Es enthält keinen LinguaLoop-Quellcode.

## Erste Installation
Lade unter **Releases** `LinguaLoop-Setup-v1.0.0.exe` herunter und starte die Setup-Datei. Sie installiert LinguaLoop pro Benutzer, erstellt Desktop- und Startmenü-Verknüpfungen und legt den Update-Prüfer in den Windows-Autostart.

## Automatische Updates
Jedes Release enthält außerdem ein ZIP nach dem Muster `LinguaLoop-vX.Y.Z-win-x64.zip`. Der Prüfer lädt die neueste Version automatisch herunter und installiert sie. Vokabeln und Lernstand bleiben auf dem jeweiligen PC.
